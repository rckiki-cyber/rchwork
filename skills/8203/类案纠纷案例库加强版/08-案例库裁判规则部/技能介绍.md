# 案例库裁判规则部 Skill 简介

## 一句话简介

这是一个面向中国民商事争议问答的裁判规则 skill 集合。每个 skill 对应一个具体案由，背后以人民法院案例库入库案例提炼的裁判规则为支撑，把专业裁判要旨转化为普通人听得懂、能行动的法律问答。

## 完整介绍

案例库裁判规则部是一组按案由拆分的法律问答 skill，覆盖合同、侵权、公司、破产、知识产权、劳动、婚姻家庭、继承、物权、金融保险、票据证券、海事海商、执行异议、仲裁与程序类案件等常见民商事争议。

这组 skill 的核心价值不是简单罗列法条，而是把人民法院案例库中的入库案例转化为可复用的裁判规则：用户提出一个具体问题后，对应案由 skill 会帮助模型识别争议焦点，提取法院通常关注的事实、证据、法律关系和裁判倾向，再用普通人能理解的方式回答“这件事大概怎么看、关键卡在哪里、要准备什么证据、主要风险是什么、下一步可以怎么做”。

每个 skill 都坚持普通人问答视角，不把回答写成判决书、代理词或法律研究报告。它适合用于法律咨询初筛、类案规则提示、争议焦点梳理、证据准备提醒和风险判断，也可以作为法律智能体在民商事场景下的案由级知识底座。

## 规模与覆盖

- 当前目录共包含 257 个案由 skill。
- 按各 skill 自述口径累计，覆盖 2273 个人民法院案例库入库案例规则条目。
- 每个 skill 通常包含：定位、触发场景、回答原则、裁判规则判断点、建议回答形态、问答示例和裁判规则知识库。

## 主要能力

1. 案由级精准触发：围绕“买卖合同纠纷”“借款合同纠纷”“劳动争议”“商标权权属、侵权纠纷”等具体案由触发，而不是泛泛回答法律问题。
2. 裁判规则支撑：回答时可引用入库案例编号，帮助用户知道判断依据来自案例库，而不是凭空推测。
3. 普通人表达：先给结论倾向，再解释原因，避免一上来堆法条或写成专业文书。
4. 争议焦点拆解：围绕合同效力、违约责任、侵权构成、赔偿计算、举证责任、管辖程序等问题拆解。
5. 行动建议导向：提示用户保留合同、转账记录、聊天记录、发票、鉴定材料、解除通知、社保记录等关键证据。

## 典型覆盖门类

### 合同与交易纠纷

包括合同纠纷、买卖合同纠纷、借款合同纠纷、租赁合同纠纷、建设工程合同纠纷、房屋买卖合同纠纷、服务合同纠纷、委托合同纠纷、保证合同纠纷、融资租赁合同纠纷、定金合同纠纷、技术合同纠纷等。适合回答合同是否有效、违约金能否调整、对方不付款怎么办、担保人是否担责、定金能不能退、借款利息是否合法等问题。

### 知识产权与竞争纠纷

包括专利权权属、侵权纠纷，商标权权属、侵权纠纷，著作权权属、侵权纠纷，侵害商业秘密纠纷，不正当竞争纠纷，仿冒纠纷，虚假宣传纠纷，商业诋毁纠纷，植物新品种权权属、侵权纠纷等。适合处理侵权认定、合法来源抗辩、惩罚性赔偿、商业秘密保护、数据抓取、刷流量、仿冒混淆、驰名商标保护等问题。

### 公司、股权与破产纠纷

包括股权转让纠纷、股东出资纠纷、股东知情权纠纷、公司决议纠纷、公司解散纠纷、损害公司利益责任纠纷、破产债权确认纠纷、破产撤销权纠纷、申请破产重整、申请破产清算等。适合用于股东权利、公司僵局、出资责任、清算责任、破产程序和债权确认等场景。

### 劳动、人身与人格权益纠纷

包括劳动争议、劳动合同纠纷、社会保险纠纷、生命权、身体权、健康权纠纷、名誉权纠纷、肖像权纠纷、隐私权、个人信息保护纠纷、一般人格权纠纷等。适合回答违法解除、社保缴纳、竞业限制、隐形加班、交通事故、人身损害、名誉侵权、个人信息保护等问题。

### 婚姻家庭、继承与物权纠纷

包括离婚纠纷、离婚后财产纠纷、婚约财产纠纷、抚养纠纷、赡养纠纷、探望权纠纷、继承纠纷、法定继承纠纷、遗嘱继承纠纷、共有纠纷、相邻关系纠纷、所有权纠纷、物权保护纠纷等。适合处理彩礼返还、夫妻共同财产、子女抚养、遗产分割、共同购房、邻里纠纷等问题。

### 金融、保险、票据与证券纠纷

包括财产保险合同纠纷、人身保险合同纠纷、银行卡纠纷、票据纠纷、票据追索权纠纷、证券交易合同纠纷、证券欺诈责任纠纷、期货交易纠纷、金融衍生品种交易纠纷、信用证纠纷等。适合回答保险拒赔、票据追索、银行卡盗刷、证券虚假陈述、期货强平、信用证欺诈等问题。

### 海事海商、交通运输与环境公益

包括海上、通海水域货物运输合同纠纷，船舶碰撞损害责任纠纷，船舶买卖合同纠纷，航次租船合同纠纷，海事海商纠纷，机动车交通事故责任纠纷，铁路运输损害责任纠纷，环境污染责任纠纷，生态环境保护民事公益诉讼等。适合处理运输责任、船舶纠纷、交通事故、环境污染和公益诉讼等问题。

### 程序、执行、仲裁与保全

包括执行异议之诉、执行分配方案异议之诉、第三人撤销之诉、追加、变更被执行人异议之诉、仲裁程序案件、申请撤销仲裁裁决、申请确认仲裁协议效力、申请诉前行为保全、因申请财产保全损害责任纠纷等。适合处理管辖、执行异议、案外人权利、仲裁效力、保全错误赔偿等程序性问题。

## 适用场景

- 普通用户想知道“我的情况法院大概会怎么看”。
- 律师、法务或法律助理做初步类案规则检索。
- 法律问答产品需要案由级裁判规则支撑。
- 需要把专业裁判要旨转写成用户可理解的咨询回答。
- 需要快速生成争议焦点、证据清单、风险提示和下一步行动建议。

## 不适用边界

- 不替代律师对具体案件的完整代理意见。
- 不直接输出判决书、起诉状、答辩状、代理词等正式法律文书。
- 不承诺案件结果，只给基于案例库规则的倾向性判断。
- 对法律、司法解释或地方裁判口径可能发生变化的问题，应结合现行有效法律和最新规则再核验。

## 对外展示版文案

案例库裁判规则部是一组面向中国民商事争议的案由级法律问答 skill。它将人民法院案例库入库案例中的裁判规则拆解到具体案由中，覆盖合同、侵权、公司、破产、知识产权、劳动、婚姻家庭、继承、物权、金融保险、海事海商、执行与仲裁等 257 个民商事场景。

当用户提出“被公司违法解雇怎么办”“买车被骗能不能三倍赔偿”“朋友借钱不还怎么起诉”“商标被别人用了算不算侵权”“工程款要不回来怎么办”等问题时，对应 skill 会以案例库规则为底座，给出普通人能听懂的结论、关键事实、证据提示、裁判倾向和下一步建议。

这套 skill 的定位是让裁判规则真正进入问答场景：不堆法条，不装成法官，也不写成代理词，而是把复杂的法律判断翻译成清楚、稳妥、可行动的回答。
