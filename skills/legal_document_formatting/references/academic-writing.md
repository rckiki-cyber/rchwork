## 1. 模板优先

学校、学院、导师、期刊和会议模板具有最高格式权威。拿到模板后：

- 以模板为输出底稿；
- 保留封面字段、节、页眉页脚、页码起算、样式 ID、目录和题注；
- 只替换示例内容，不从零重建复杂模板；
- 不把学校封面“美化”为自创封面；
- 不改变引用体例、匿名审稿要求、字数和行号设置。

本文件只在模板未规定或规则缺失时提供默认值。

## 2. 文档分区

完整学位论文通常按以下顺序分区：

1. 外封面/内封面；
2. 原创性声明和授权书；
3. 中文摘要与关键词；
4. 英文摘要与关键词；
5. 目录；
6. 图表清单、缩略语表（需要时）；
7. 正文；
8. 参考文献；
9. 附录；
10. 致谢；
11. 在学成果或作者简介（需要时）。

各区通过分节符控制首页、页眉页脚和页码。不得用多个空白页模拟奇数页起章；模板要求奇数页时使用 oddPage 分节符。

## 3. 默认页面与字体

### 3.1 学位论文默认

| 项目 | 默认值 |
|---|---|
| 纸张 | A4 纵向 |
| 页边距 | 上/下 25.4 mm，左/右 31.8 mm |
| 装订线 | 左侧 5 mm（仅在学校要求时） |
| 中文正文 | 宋体 10.5 或 12 pt |
| 西文/数字 | Times New Roman，同字号 |
| 行距 | 1.5 倍或固定 20—24 pt，以学校规则为准 |
| 段落 | 两端对齐，首行 2 字符，段前后 0 |

### 3.2 期刊和课程论文默认

无模板时用 A4、四周 25 mm；正文宋体 10.5—12 pt；标题 18 pt；行距 1.5 倍。双栏只能在期刊模板明确要求时使用。

## 4. 封面、摘要和目录

### 4.1 封面

- 完全遵照学校或期刊模板；
- 校名、徽标、论文题目、作者、学号、专业、导师、日期分别使用独立样式或稳定表格；
- 不用空格和下划线字符对齐字段；
- 论文题目换行保持语义完整，不将介词、标点或短词孤立；
- 徽标保持比例和清晰度，不擅自改色；
- 封面一般不显示页码。

### 4.2 摘要

- “摘要”标题 16—18 pt，居中；
- 摘要正文 10.5—12 pt，两端对齐；
- “关键词：”加粗；3—8 个关键词用分号分隔；
- 中文摘要与英文 Abstract 各自独立分节或至少独立起页；
- 英文摘要使用 Times New Roman，避免把全部英文强制设置为中文字体。

### 4.3 目录

- 用 TOC 字段自动生成；
- 一般显示三级标题；
- “目录”标题居中，不进入自身目录；
- 条目使用制表位和点引导线，不手打点线；
- 目录页码与正文页码分节时保持链接正确；
- 最终更新全部域，检查标题和页码。

## 5. 正文标题与段落

无模板时可用：

| 角色 | 格式 |
|---|---|
| 论文主标题 | 18—22 pt，黑体/宋体加粗，居中 |
| 一级标题 | 16 pt，黑体，居中或左对齐 |
| 二级标题 | 14 pt，黑体，左对齐 |
| 三级标题 | 12 pt，宋体加粗或楷体，左对齐 |
| 四级标题 | 12 pt，宋体加粗，段首式 |
| 正文 | 10.5—12 pt，宋体，首行 2 字符 |

标题编号使用学校模板；无模板时选：

- 人文社科中文：`一、` → `（一）` → `1.` → `（1）`；
- 章节制：`第1章` → `1.1` → `1.1.1`；
- 英文论文：`1` → `1.1` → `1.1.1`。

标题最多四级；同一级标题前后间距一致。标题后至少跟两行正文。

## 6. 引注、参考文献、图表和公式

### 6.1 引注

遵照学校/期刊指定体例。未指定时：

- 中国法学论文优先使用脚注；
- 跨学科研究可使用 GB/T 7714 顺序编码或著者—年份制；
- 英文论文按指定 APA、Chicago、MLA、Bluebook 等体例。

脚注必须使用真实脚注：

| 属性 | 默认值 |
|---|---|
| 字体 | 中文宋体，西文 Times New Roman |
| 字号 | 9 pt |
| 行距 | 单倍 |
| 对齐 | 两端对齐 |
| 首行 | 悬挂缩进，使续行与注释正文对齐 |
| 段前后 | 0 |

同一来源的作者、题名、出版信息、页码和标点必须全篇一致。不得把引用管理器字段转换成乱码或在清理样式时删除脚注关系。

### 6.2 参考文献

- 独立起页；
- 标题与一级标题一致；
- 条目使用悬挂缩进；
- 中英文按模板排序或分组；
- DOI 和 URL 可点击，但避免蓝色下划线破坏打印风格；可保留超链接而将显示样式改为黑色；
- 核对正文引注与参考文献一一对应。

### 6.3 图表

- 表题置于表上，图题置于图下；
- 题注 10.5 pt，居中；
- 使用 Caption 和 SEQ 自动编号；
- 图表与题注同页；
- 统计表优先三线表，证据/清单型表格可用完整网格；
- 图中文字不小于 9 pt；
- 注释和数据来源置于图表下方 9 pt；
- 正文用交叉引用字段引用“图 2”“表 3”。

### 6.4 公式

- 用 Word 公式/OMML；
- 公式居中，编号右对齐；
- 公式前后 6 pt；
- 变量斜体，函数、数字和单位正体；
- 长公式换行在运算符处，等号对齐。

## 7. 页眉页脚与分节

典型规则：

- 封面：无页眉页脚；
- 摘要、目录：罗马数字 `I, II, III` 或学校指定格式；
- 正文：阿拉伯数字从 1 开始；
- 参考文献和附录：通常续正文页码；
- 奇偶页页眉：左页可写论文题目，右页可写章标题；只有模板要求时使用；
- 页码放页脚居中或外侧；
- 每个节都检查“链接到前一节”和起始页码。

## 8. 课程论文、期刊稿与学位论文差异

### 8.1 课程论文

通常不需要复杂封面、多节页码和图表清单。用简洁首页：课程、题目、作者、学号、日期。篇幅少于 10 页时可不单设目录。

### 8.2 期刊投稿

完全按投稿模板。匿名审稿稿件删除作者、单位、基金、致谢和文档属性中的身份信息。需要行号、双倍行距或双栏时按期刊要求，不应用学位论文默认。

### 8.3 学位论文

必须保留学校模板的多节结构、声明页、封面、页码和页眉。结构复杂时采用“模板为底稿、分区替换内容”，不要将普通正文复制后全局套样式。

## 9. 最终检查

- [ ] 学校/期刊模板和最新版指南已优先。
- [ ] 封面字段、摘要、关键词、目录和正文分区完整。
- [ ] 标题样式有大纲级别，目录可更新。
- [ ] 前置页与正文页码分节、起算和显示正确。
- [ ] 脚注是真实脚注，参考文献体例统一。
- [ ] 图表、公式、题注和交叉引用可更新。
- [ ] 无标题悬空、脚注跨页异常、表格断裂和大面积空白。
- [ ] 匿名稿已清理身份信息和文档属性。
- [ ] PDF/打印渲染与 Word 页面一致。
