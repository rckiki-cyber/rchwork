# Channel brand assets

These local PNG assets are the current official application icons distributed by
the platform publishers through the Mac App Store:

- `qq.png` — Tencent QQ (`com.tencent.qq`)
- `dingtalk.png` — DingTalk (`5ZSL2CJU2T.com.dingtalk.mac`)
- `wecom.png` — WeCom (`com.tencent.WeWorkMac`)

They are UI identifiers for their respective connection channels. Do not replace
them with hand-drawn approximations.
